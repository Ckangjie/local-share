# 本地服务一键公网分享工具

## 1. 项目概述

### 1.1 项目定位

一款面向**开发人员和普通用户**的 Windows 桌面工具。

用于将本机正在运行的 Web 服务，通过 Cloudflare Quick Tunnel 一键映射到公网，并自动生成一个临时公网访问地址。

用户无需手动执行 `cloudflared` 命令，无需配置 DNS、固定域名或 Cloudflare Tunnel。

典型场景：

- 开发人员将本地开发页面发送给客户预览
- 给产品经理、测试人员临时查看本地页面
- 手机访问电脑上的本地 Web 项目
- 给同事演示本地项目
- 普通用户临时将本地 Web 服务分享给其他人

Cloudflare Quick Tunnel 可以直接通过 `cloudflared tunnel --url http://localhost:8080` 创建随机 `trycloudflare.com` 地址，不需要将自己的域名加入 Cloudflare DNS。官方将 Quick Tunnel 定位为开发和测试用途。

# 4. V1 功能范围

## 4.1 本地服务自动检测

# 5. 公网分享

用户选择：

```text
localhost:5173
```

点击：

```text
开始分享
```

应用内部启动：

```bash
cloudflared tunnel --url http://localhost:5173
```

Cloudflare Quick Tunnel 会生成随机的：

```text
https://xxxxx.trycloudflare.com
```

该地址可以直接发送给其他人访问。

---

# 6. 公网地址获取

应用需要监听 `cloudflared` 进程输出。

例如：

```text

```

程序提取：

```text
https://abc123.trycloudflare.com
```

然后展示：

```text

[复制地址]
[打开地址]
```

# 8. 停止分享

点击：

```text
停止分享
```

应用结束当前 `cloudflared` 进程。

状态恢复：

```text
○ 未分享
```

公网地址失效。

# 9. 自动刷新服务列表

本机服务可能随时启动或关闭。

因此可以提供：

建议 V1：

```text

```

# 14. 为什么选择 Tauri

Tauri 可以将外部二进制作为 Sidecar 打包进桌面应用，因此用户不需要单独安装 `cloudflared`。Tauri 官方支持通过 `externalBin` 配置嵌入外部二进制，并可以从 JavaScript/Rust 启动 Sidecar。

最终用户体验：

```text
LocalShare.exe
```

双击即可使用。

不要求用户安装：

```text
Node.js
Rust
cloudflared
Git
```

# 17. 端口检测流程

```text
开始扫描
    ↓
获取本机 LISTENING TCP 端口
    ↓
过滤系统端口
    ↓
HTTP 请求探测
    ↓
判断是否 Web 服务
    ↓
生成服务列表
    ↓
展示给用户
```

例如：

```text
5173 → HTTP 200 → Web 服务 ✓
8080 → HTTP 200 → Web 服务 ✓
3306 → HTTP失败 → 数据库服务 → 不展示
6379 → HTTP失败 → Redis → 不展示
```

# 23. Quick Tunnel 的限制

Quick Tunnel 适合：

```text
开发
测试
Demo
临时分享
客户预览
```

不建议用于：

```text
生产系统
长期稳定服务
正式业务
高并发服务
```

Cloudflare 官方明确说明 Quick Tunnel 用于测试和开发，并存在并发请求等限制；正式生产环境应该使用正式 Tunnel。
